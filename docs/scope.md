# Project Scope

## Must Have

The system must:

- Allow a billing employee to create a new invoice.
- Allow invoice charges and amounts to be entered.
- Calculate the total invoice amount.
- Allow an invoice to be submitted for review.
- Allow an authorized user to approve or reject an invoice.
- Track the current status of the invoice.
- Allow rejected invoices to be corrected and resubmitted.

## Should Have

If time permits, the system should:

- Allow users to search for existing invoices.
- Allow users to view invoice history.
- Display comments or reasons when an invoice is rejected.

## Could Have

Optional enhancements could include:

- A dashboard showing invoice counts by status.
- Additional invoice search and filtering options.
- Notifications when an invoice's status changes.

## Won't Have This Semester

The system will not:

- Send actual invoices to clients.
- Process real payments.
- Integrate with an accounting or payment system.
- Use real client or company financial data.
