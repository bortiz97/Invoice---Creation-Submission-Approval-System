# Project Charter

## Project Structure
This capstone project will be completed individually. I will be responsible for the planning, development, testing, documentation, and maintenance of the project repository.

## Communication
Because this is an individual project, communication with team members is not required. I will communicate with the instructor when clarification, feedback, or approval is needed.

## Work Management
Project tasks will be divided into smaller milestones and completed according to the course schedule. GitHub will be used to document progress and maintain the project's version history.

## Git and GitHub Practices
I will use meaningful commit messages that describe the changes made to the project. As development progresses, branches will be used when appropriate for new features or significant changes before they are added to the main branch.

## Quality and Testing
I will review requirements, business rules, documentation, and application functionality throughout development. Features will be tested against the defined requirements and acceptance criteria before being considered complete.

## Responsibilities
As the sole project member, I am responsible for:

- Requirements and business rules
- System design
- Application development
- Testing
- Documentation
- GitHub repository management
- Final project submission

## Project Accountability
I will monitor project deadlines and progress each week. If work falls behind schedule, I will prioritize the required features within the defined project scope before working on optional enhancements.
